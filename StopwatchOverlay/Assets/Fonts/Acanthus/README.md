# Acanthus bundled typography

These unmodified static TrueType fonts are scoped to the Acanthus theme. They are
embedded WPF resources, not installed into Windows. Other theme font resources
continue to use their existing families.

All three projects distribute these fonts under SIL Open Font License 1.1; the
copyright notices and license are preserved in `OFL.txt`. That file is copied
beside the application's published resources, including single-file publishes.

## Sources

- **Cormorant Garamond** Regular and SemiBold: [Catharsis Fonts official repository](https://github.com/CatharsisFonts/Cormorant/tree/9719e26aa8e26d7a30e736667427b9e05b5db059/fonts/ttf), commit `9719e26aa8e26d7a30e736667427b9e05b5db059`.
- **Inter** Regular, Medium and SemiBold: [official Inter v4.1 release](https://github.com/rsms/inter/releases/tag/v4.1), `Inter-4.1.zip`, `extras/ttf/`.
- **Cascadia Mono** Regular and SemiBold: [Microsoft official v2407.24 release](https://github.com/microsoft/cascadia-code/releases/tag/v2407.24), `CascadiaCode-2407.24.zip`, `ttf/static/`.

No variable fonts, conversions, subsetting, or renamed font families are used.
The family names recognized by WPF are `Inter`, `Cormorant Garamond`, and
`Cascadia Mono`.
